# cell-journey
# 🔬 세포소기관 탐험대 (cell-journey)

고등학교 생명과학 과정 연계 인터랙티브 세포 학습 웹앱입니다.

## 📌 프로젝트 소개
단순히 글로 읽는 학습이 아니라, 사용자가 직접 세포 구조를 탐색하고 세포소기관의 구조와 기능, 단백질 분비 경로 시뮬레이션을 탐구할 수 있는 웹 애플리케이션입니다.

## 🚀 주요 기능
- **Home (세포 한눈에 보기):** 동물세포의 주요 소기관 위치 시각화
- **Organelle Explorer (소기관 탐구):** 9종 소기관의 상세 정보 및 세부 구조(크리스타, 핵공 등) 인터랙티브 탐색
- **Quiz & Simulation (학습 확인):** 생명과학 개념 확인 퀴즈 및 단백질 분비 과정 슬라이더 시뮬레이션
